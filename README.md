# 量潮代码中心 (`qtcode`)

量潮软件工程产品平台：软件工程实践、规范与档案的公开展示。

## 仓库目录

```
qtcode/
├── docs/ # 所有非代码文档
│   ├── brd/ # 业务需求文档：业务场景和痛点
│   ├── prd/ # 产品需求文档：功能规格、用户故事、验收标准
│   ├── ixd/ # 交互设计文档：原型、流程、组件交互规则
│   ├── qa/ # 质量保障文档：测试用例、验收 checklist、合规验证
│   ├── add/ # 架构设计文档：技术方案和实现细节
│   ├── dev/ # 开发者文档：API 参考、集成指南、本地开发说明
│   └── user/ # 用户文档：操作手册与配置指南
└── src/ # 源代码
    └── site/ # 公网展示站（量潮代码中心官网）
```

## 关联

- 领域第二大脑：`quanttide-code`（软件工程）
- 云平台：`qtcloud-code`（量潮代码云）
